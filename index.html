2.1 • Projeto Acadêmico (API — FATEC SJC)

Kredita — Inteligência Territorial de Crédito

Aprendizagem por Projetos Integrados desenvolvida no 1º semestre do curso de Desenvolvimento de Software Multiplataforma, utilizando metodologia ágil Scrum e dados econômicos públicos.

API • 1º Semestre DSM

Kredita

Empresa parceira: Parceiro fictício (cenário acadêmico FATEC SJC)

Repositório no GitHub (Fork)

Situação-Problema

Conceder crédito para populações historicamente recusadas por grandes instituições financeiras exige ir além da visão tradicional de risco: exige identificar onde residem o consumo reprimido e a capacidade real de pagamento sustentável. Neste projeto, o objetivo foi explorar e transformar dados econômicos públicos do Banco Central do Brasil (BCB) em inteligência territorial para apoiar decisões de crédito mais inclusivas e responsáveis.

Solução Desenvolvida

Aplicação web com cálculo de score regional de oportunidade de crédito, integrando bases públicas do Banco Central (SGS, SCR.data, Olinda), IBGE (SIDRA), Novo CAGED e CGU. Os indicadores são tratados em Python e disponibilizados via API REST em Flask para visualização clara em interface web responsiva.

Contribuições Pessoais

  • Estruturação da interface web com foco em usabilidade, clareza na leitura de indicadores e responsividade.
  • Desenvolvimento de componentes front-end e integração visual com o fluxo de consultas da API.
  • Colaboração nas cerimônias Scrum, organização de backlog e revisões de entrega entre sprints.

Hard Skills Adquiridas

  • Desenvolvimento front-end responsivo com HTML5, CSS3, Bootstrap 5 e JavaScript.
  • Integração entre front-end e API REST construída com Python e Flask.
  • Exploração e tratamento de dados públicos com Python no Google Colab.
  • Versionamento colaborativo em equipe utilizando Git e GitHub.

Soft Skills Exercitadas

  • Gestão de tempo, priorização por sprint e resolução colaborativa de problemas.
