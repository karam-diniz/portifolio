## Identidade Visual

- **Cores oficiais (Karam Design):** `#1D1D1B` (grafite escuro) e `#FFFEDE` (creme suave), com alternância entre modo escuro e modo claro.
- **Tipografia:** Montserrat (Google Fonts).

## Como publicar no GitHub Pages

1. Crie ou abra o repositório `karam-diniz.github.io` no GitHub.
2. Extraia o conteúdo desta pasta na raiz do repositório.
3. Faça `git add .`, `git commit -m "Publica portfólio"` e `git push`.
4. Em **Settings > Pages**, verifique se a branch `main` (`/root`) está ativa.
